# Assessment 01.05 — Processor Architecture and CPU Internals

## 1. Purpose

This assessment verifies that you understand how processors execute instructions, how cores and logical processors relate to operating-system scheduling, and how CPU architecture affects cloud sizing, container behavior, and performance troubleshooting.

The objective is not to memorize component names. You should be able to interpret metrics, identify likely bottlenecks, and explain why apparently similar processors or vCPU configurations can behave differently.

## 2. Mastery Requirement

The required mastery score is **95%**.

| Dimension | Weight |
|---|---:|
| Processor architecture | 25% |
| Execution and performance concepts | 25% |
| Systems and cloud application | 30% |
