# Assessment 01.08 — Computer Interconnects, PCIe, DMA, Interrupts, and I/O Architecture

## 1. Purpose

This assessment verifies that you understand how processors, memory, device controllers, operating systems, and peripheral devices cooperate to perform input/output operations.

You should be able to explain the complete I/O path, distinguish polling from interrupts and DMA, interpret queues and buffering, identify link or interrupt bottlenecks, and apply these concepts to storage, networking, GPUs, virtual machines, containers, Kubernetes, and AWS.

## 2. Mastery Requirement

The required mastery score is **95%**.

| Dimension | Weight |
|---|---:|
| Interconnect and device architecture | 25% |
| Interrupt, DMA, queue, and buffer concepts | 25% |
| Virtualization, container, and cloud application | 25% |
| Troubleshooting and architecture reasoning | 25% |

Any dimension below 80% requires revision.
