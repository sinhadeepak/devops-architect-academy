# Assessment 01.04 — Boolean Logic and Digital Circuits

## 1. Purpose

This assessment verifies that you can reason accurately about Boolean expressions, truth tables, logic gates, combinational circuits, sequential circuits, and real-world decision rules.

The objective is not merely to identify gate symbols. You should be able to design, validate, simplify, and troubleshoot logic used in processors, software, networking, authorization, monitoring, and CI/CD systems.

## 2. Mastery Requirement

The required mastery score is **95%**.

| Dimension | Weight |
|---|---:|
| Boolean logic fluency | 30% |
| Digital-circuit understanding | 25% |
| Systems application | 25% |
| Security and architecture reasoning | 20% |

Any dimension below 80% requires revision.
