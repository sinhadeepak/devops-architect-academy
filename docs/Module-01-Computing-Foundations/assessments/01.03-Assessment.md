# Assessment 01.03 — Binary, Data Representation, and Number Systems

## 1. Purpose

This assessment verifies that you understand how computers represent numbers, text, permissions, addresses, instructions, and other data using binary states.

The objective is not to memorize conversion procedures in isolation. You should be able to apply number-system knowledge to networking, Linux permissions, storage, encoding, security, and systems architecture.

| Dimension | Weight |
|---|---:|

| Data representation | 25% |
| Systems application | 25% |

## 14. Section L — Representation Risk Scenarios

For each scenario, identify the risk, likely symptom, and mitigation.

### Scenario 1 — Counter Overflow

A retry counter uses an unsigned 8-bit integer.

### Scenario 2 — File Size Limit

An API stores file sizes in a signed 32-bit integer.

### Scenario 3 — Encoding Mismatch

A producer writes UTF-8, but a consumer assumes another character encoding.

### Scenario 4 — Unvalidated Numeric Input

A service accepts an arbitrary integer and passes it to a lower-level library expecting a 16-bit value.

### Scenario 5 — Incorrect Permission Mask

A deployment script combines permission flags incorrectly and grants unintended write access.

### Scenario 6 — Storage Forecast Error

A capacity plan treats TB and TiB as equivalent across a multi-petabyte environment.
