# Lab 01.03 — Binary and Number Systems

## 1. Lab Objective

This lab develops practical fluency with binary, octal, decimal, and hexadecimal representation. You will perform manual conversions, validate them with operating-system tools, inspect real values from networking and Linux permissions, and analyze how representation affects storage, encoding, and architecture decisions.

The goal is not speed. The goal is to understand what each representation means and where it appears in systems engineering.

## 2. Expected Outcomes

After completing this lab, you should be able to:

- Convert values among decimal, binary, octal, and hexadecimal.
- Explain the range provided by common integer widths.
- Interpret Linux permission values in binary and octal.
- Convert IPv4 octets between decimal and binary.
- Inspect character encodings.
- Distinguish decimal and binary storage measurements.
- Use bitwise operations to analyze masks and flags.
- Identify representation-related risks.

## 3. Required Tools

Use any of the following:

- Paper or a text editor for manual work
- PowerShell
- Bash
- Python 3, where available
- Calculator only for validation after manual work

## 9. Part F — Bitwise Operations

Calculate the following manually:

```text
10101100 AND 11110000
10101100 OR  11110000
10101100 XOR 11110000
NOT 10101100
```

Validate with Python:

```python
a = 0b10101100
b = 0b11110000

print(f"AND: {a & b:08b}")
print(f"OR:  {a | b:08b}")
print(f"XOR: {a ^ b:08b}")
print(f"NOT: {(~a) & 0xFF:08b}")
```

Explain why the NOT operation is masked with `0xFF` in this example.
