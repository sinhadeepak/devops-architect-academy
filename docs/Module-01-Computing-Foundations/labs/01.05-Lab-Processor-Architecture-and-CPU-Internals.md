# Lab 01.05 — Processor Architecture and CPU Internals

## 1. Lab Objective

This lab connects CPU architecture concepts to a real computer. You will inspect processor topology, logical processors, cache information, utilization, process behavior, per-core load, and CPU-bound versus I/O-bound workloads.

The purpose is to learn how to interpret CPU metrics rather than merely collect them.

## 2. Expected Outcomes

After completing this lab, you should be able to:

- Identify processor architecture, cores, and logical processors.
- Distinguish physical cores from hardware threads.
- Observe per-process and per-core CPU consumption.
- Compare CPU-bound and I/O-bound workloads.
- Explain aggregate CPU utilization correctly.
- Identify possible throttling, saturation, or serialization.
- Produce a structured CPU investigation report.

## 3. Safety

Use only temporary files and test processes. Do not run stress tests on production systems, shared servers, corporate-managed systems without authorization, or devices with thermal or stability problems.

## 8. Part E — Create a Single-Threaded CPU Workload

Create `single_cpu.py`:

```python
import math
import time

end = time.time() + 30
count = 0

while time.time() < end:
    for value in range(2, 10000):
        limit = int(math.sqrt(value)) + 1
        is_prime = all(value % divisor for divisor in range(2, limit))
        if is_prime:
            count += 1

print(f"Completed operations: {count}")
```

Run:

```bash
python single_cpu.py
```

Observe CPU utilization while it runs.

Answer:

1. Is one logical processor near saturation?
2. What does aggregate utilization show?
3. On an eight-logical-processor system, approximately what aggregate value could one saturated thread produce?
4. Why does adding cores not automatically accelerate this program?

## 9. Part F — Create a Multi-Process CPU Workload

Create `multi_cpu.py`:

```python
from multiprocessing import Process, cpu_count
import math
import time


def work(seconds: int) -> None:
    end = time.time() + seconds
    count = 0
    while time.time() < end:
        for value in range(2, 10000):
            limit = int(math.sqrt(value)) + 1
            if all(value % divisor for divisor in range(2, limit)):
                count += 1
    print(count)


if __name__ == "__main__":
    workers = max(1, min(cpu_count(), 4))
    processes = [Process(target=work, args=(30,)) for _ in range(workers)]

    for process in processes:
        process.start()

    for process in processes:
        process.join()
```

Run it and compare with the single-threaded workload.

Document:

- Number of worker processes
- Number of busy logical processors
- Aggregate utilization
- Responsiveness of the system
- Whether performance scaled linearly

Explain why scaling may not be perfectly linear.
