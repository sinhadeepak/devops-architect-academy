# Lab 01.04 — Boolean Logic and Digital Circuits

## 1. Lab Objective

This lab develops practical fluency with Boolean expressions, truth tables, logic gates, bit masks, decision rules, and state-based behavior. You will apply the same logical foundations to hardware concepts, programming conditions, Linux shell control, network masks, access rules, monitoring alerts, and CI/CD gates.

The goal is to move beyond memorizing gate definitions and learn how to design, validate, and troubleshoot logical behavior.

## 2. Expected Outcomes

After completing this lab, you should be able to:

- Build truth tables for common and compound Boolean expressions.
- Apply AND, OR, NOT, XOR, NAND, NOR, and XNOR correctly.
- Verify De Morgan's laws.
- Model a half adder and full adder.
- Distinguish combinational logic from stateful sequential logic.
- Apply Boolean reasoning to shell commands, access control, monitoring, networking, and deployment decisions.
- Identify unsafe or ambiguous decision rules.

## 3. Required Tools

Use:

- A text editor
- Paper for manual truth tables
- Python 3 where available
- Bash or PowerShell for shell-condition exercises

No hardware simulator is required.

## 7. Part D — Verify De Morgan's Laws

Create truth tables proving:

```text
NOT (A AND B) = (NOT A) OR (NOT B)
```

and:

```text
NOT (A OR B) = (NOT A) AND (NOT B)
```

Use Python to validate:

```python
values = [False, True]

for a in values:
    for b in values:
        left_1 = not (a and b)
        right_1 = (not a) or (not b)
        left_2 = not (a or b)
        right_2 = (not a) and (not b)
        print(a, b, left_1, right_1, left_2, right_2)
```

Explain why De Morgan's laws are useful in authorization and firewall logic.

## 8. Part E — Model a Half Adder

Complete the half-adder truth table.

| A | B | Sum | Carry |
|---:|---:|---:|---:|
| 0 | 0 | | |
| 0 | 1 | | |
| 1 | 0 | | |
| 1 | 1 | | |

Use:

```text
Sum = A XOR B
Carry = A AND B
```

Then implement in Python:

```python
def half_adder(a: int, b: int) -> tuple[int, int]:
    total = a ^ b
    carry = a & b
    return total, carry
```

Validate all four input combinations.

## 9. Part F — Model a Full Adder

A full adder accepts:

- A
- B
- Carry-in

and produces:

- Sum
- Carry-out

Complete the truth table for all eight combinations.

Use:

```text
Sum = A XOR B XOR CarryIn
```

```text
CarryOut = (A AND B) OR (CarryIn AND (A XOR B))
```

Implement:

```python
def full_adder(a: int, b: int, carry_in: int) -> tuple[int, int]:
    total = a ^ b ^ carry_in
    carry_out = (a & b) | (carry_in & (a ^ b))
    return total, carry_out
```

Explain how multiple full adders can add multi-bit numbers.
